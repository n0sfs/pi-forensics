This is a self-signed certificate, so every browser will warn on first visit until you import it as trusted on each device that connects here - the private key never leaves this station, only the public certificate is ever downloaded.
Download Certificate (.crt)

  1. Download the certificate above, then double-click the pi-forensics.crt file.
  2. Click Install Certificate..., choose Local Machine (needs admin) or Current User, then Next.
  3. Choose Place all certificates in the following store → Browse → Trusted Root Certification Authorities → OK → Next → Finish.
  4. Restart your browser and reload this page.

  1. Download the certificate above, then double-click it - it opens in Keychain Access.
  2. Choose the System keychain (or login for just your account) and click Add.
  3. Find the certificate in the list, double-click it, expand Trust, and set "When using this certificate" to Always Trust.
  4. Close the panel, enter your password to confirm, then restart your browser and reload this page.

System-wide trust (Debian/Ubuntu-based, affects Chrome/Chromium/Edge and most other apps):
sudo cp pi-forensics.crt /usr/local/share/ca-certificates/pi-forensics.crt
sudo update-ca-certificates
Firefox keeps its own certificate store regardless of distro - see the Firefox note below.

  1. Open this page in Safari on the device (or AirDrop the downloaded file to it) and download the certificate.
  2. Go to Settings → General → VPN & Device Management, tap the downloaded profile, then Install (enter your passcode).
  3. Then go to Settings → General → About → Certificate Trust Settings and enable full trust for this certificate.

  1. Open this page in the device's browser and download the certificate.
  2. Go to Settings → Security (or Security & Privacy) → Encryption & Credentials → Install a Certificate → CA Certificate.
  3. Browse to the downloaded file and confirm. Exact menu names vary by Android version and manufacturer.
Firefox note (any OS): Firefox keeps its own certificate store, separate from the operating system's - the steps above don't apply to it. Instead go to Firefox Settings → Privacy & Security → Certificates → View Certificates → Authorities tab → Import → select the downloaded file → check "Trust this CA to identify websites".
