PhotoRec File Carving Recovery Recovers files by signature from a device or an already-acquired image - reads source only, never writes back to it
Recovers ~480 known file types by signature (not by filesystem metadata), so it works even on damaged/reformatted media - but recovered files lose their original names/folder structure. Progress shown is bytes recovered so far and the live log; PhotoRec doesn't report a reliable overall percentage in scripted mode.
Quick Triage Scan Finds emails, URLs, IP addresses, card-like numbers, and phone numbers - built in, no external tool required, read-only against the source
Writes one text file per category (emails.txt, urls.txt, etc.) that can be opened in any text editor - a good first pass before deeper analysis, and beginner-friendly since no filesystem or partition knowledge is required. Built in-house rather than depending on an external tool, so it works on any system this app runs on - a straightforward Python scan, not a highly-optimized C tool, so it's noticeably slower on very large (multi-TB) images.
