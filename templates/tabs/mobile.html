Extract SMS via Companion App (Non-Rooted)
Installs a small companion app (hand-built for this project, mirroring the same open-source relay-provider design as the collector below) on the device to read SMS through Android's own normal permission system - the only way to get real SMS content from a non-rooted, non-backup-eligible messaging app. This actively modifies the device (unlike Pull/Backup/Bugreport below): it installs an app, grants it a permission, queries, then uninstalls it and reverses every change - every step is disclosed in the resulting case record. Extract Contacts/Call Log via Companion App (Non-Rooted)
Installs a small companion app (hand-built for this project, mirroring the same open-source relay-provider design as the SMS collector above - all three data types ship in one app) to read Contacts and/or Call Log through Android's own normal permission system - both are excluded from `adb backup` on every device, with no way around that short of root. This actively modifies the device (installs an app, grants one or both of READ_CONTACTS/READ_CALL_LOG), but - unlike SMS - never disrupts the phone's own Contacts/Phone apps at any point, since neither permission requires becoming a "default app." Every step is disclosed in the resulting case record; the collector is always uninstalled and both permissions revoked when finished.
Copies files from the phone's visible storage (photos, downloads, documents). Reliable on any modern Android version, but only sees what's directly accessible - not inside individual apps' private data.
E01/EWF is not available for physical Android acquisition - ewfacquire requires a seekable source and cannot read from a piped adb stream. Only raw/dd output is supported here.
