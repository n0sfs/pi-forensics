Live Collection USB
Prepares a blank USB drive with live-forensics collector tooling (UAC for Linux/macOS, a hand-written PowerShell script for Windows) so it can be run on a separate, live, running target machine to gather volatile artifacts (processes, network connections, logged-on users) - not evidence acquisition, and nothing here ever touches a network. Bring the same drive back afterward to import its results into a case.
