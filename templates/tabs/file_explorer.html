Analyzes this Windows RAM image with Volatility3. Runs as a background job (see the progress bar below the toolbar) - large images or plugins like Handles/FileScan can take a while. Analyzes this Linux RAM image with mquire - needs no external debug symbols (reads BTF/kallsyms embedded directly in the image itself). x86_64 Linux kernels only for now - mquire has no ARM/aarch64 target support yet, so this will not work on a memory dump taken from another Pi or an ARM-based embedded device. Runs as a background job. Results are saved as real files (_mquire_<table>.json) next to the image, viewable by clicking them in File Explorer.

ALEAPP/iLEAPP: --
Runs a comprehensive, community-maintained, third-party mobile artifact parser against this extraction folder - hundreds of app-specific artifacts (WhatsApp, Signal, Telegram, Chrome, WiFi history, app usage, and much more), well beyond this app's own small built-in parser. Produces a self-contained HTML report plus TSV data files in a new subfolder next to this extraction, browsable in File Explorer once complete.
Select the correct parser for this extraction's platform, then click Start Scan.
